## Who does what

Your ICB provides core GP IT, including security updates and anti-virus. Practices must name someone responsible for IT, including data and cyber security, and must have a Data Protection Officer.<sup><a href="#ref-1">1</a></sup> Suppliers are responsible for the security of their own products, and you check that when you buy.

## Cyber Essentials

A government-backed certificate that shows an organisation has five basic protections in place: firewalls, secure settings, security updates, controlled user access, and malware protection.<sup><a href="#ref-2">2</a></sup>

## If something goes wrong

Tell your ICB GP IT service straight away, and report it through the DSPT. For urgent help, the NHS data security centre has a 24-hour line: 0300 303 5222.<sup><a href="#ref-3">3</a></sup> See [data breaches](/information-governance/after-go-live#data-breaches) for the rest of the steps.
